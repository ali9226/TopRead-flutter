# Tile Quest 原创音效

本目录的 7 个 WAV 完全由本项目脚本合成：阻尼振荡器、泛音、扫频及固定种子的滤波噪声。不含录音、下载采样或其他游戏的音频素材；音色与短乐句均为本模块原创。

| 文件 | 标称时长 | 音色与用途 |
| --- | ---: | --- |
| `tap.wav` | 110 ms | 带少量气声的柔和木片轻嗒，响应有效点牌。 |
| `match.wav` | 560 ms | 短泡泡 pop 接清亮上扬三音，在三张牌开始消失时触发。 |
| `tool.wav` | 260 ms | 轻风擦过、木片与短叮，提示移出和撤回。 |
| `entry.wav` | 1040 ms | 柔和落牌风声、稀疏落定声和末尾轻叮；整次入场只播一段。 |
| `shuffle.wav` | 2100 ms | 聚拢柔风、加速的多圈纸牌沙沙、减速归位和清亮收尾；整次洗牌只播一段。 |
| `won.wav` | 840 ms | 柔和上扬的四音胜利短句。 |
| `lost.wav` | 680 ms | 轻柔下行三音，避免尖锐的失败蜂鸣。 |

所有文件为 **22050 Hz、单声道、16-bit 有符号整数 PCM WAV**。7 个 WAV 总计 **246828 Bytes**（约 241 KiB，不含本说明）。采样量化可能使标称时长有不足一个采样点的偏差。

每段音符有平滑起音及衰减；导出时去除 DC，并对文件首尾施加 6 ms 余弦淡入淡出，首尾样本均为数字零。合成器限制峰值不超过满幅的 0.56；当前资产实际峰值约为 0.19–0.34。播放再使用 0.66–0.80 的各事件音量，保留叠加余量。游戏声池最多 11 个声部：点击 4 个、三消 2 个，其余各 1 个；快速连点不会无限创建播放器。

在 Flutter 项目根目录执行以下命令可完整重建：

```sh
python3 tool/tile_quest/generate_audio.py
```

固定噪声种子及确定的合成参数使同一脚本重复运行产生逐字节相同的 WAV。修改音色或时长时，应同时更新 `lib/pages/tile_quest/services/feedback_service.dart` 的事件参数，并运行 `test/pages/tile_quest/audio_feedback_test.dart`。

播放复用项目已有的 audioplayers 依赖；声源、临时缓存和播放器由游戏单独管理。Android 使用低延迟声部及 `AudioFocus.none`，iOS 使用 ambient 类别，尊重系统静音并混音。iOS 的 AVAudioSession 类别由系统共享，插件没有读取旧类别的接口；本模块退出时停止及释放自己的播放器，不停止其他模块的播放器。
