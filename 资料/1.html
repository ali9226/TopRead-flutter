活动介绍
```
活动期间，用户每完整观看一次有效广告，即可自动获得一次抽奖机会。观看广告的次数越多，获得的抽奖机会越多，赢得每周现金大奖的概率也会相应提高。
```
如何参与？
```
01  完整观看广告
在活动周期内完整观看广告，并确保广告观看记录成功提交。
02  自动获得抽奖机会
每完成一次有效广告观看，即可获得一次抽奖机会，无需手动报名。
03  等待每周开奖
系统将在每周日晚上7点，从本周全部有效抽奖机会中随机抽取5名幸运用户。
```
📊 中奖概率如何计算？
```
每一次有效广告观看，都相当于获得一张抽奖券。你拥有的抽奖券数量，占本周全部抽奖券总数的比例，就是你在单个中奖名额抽取中的中奖概率。
单个中奖名额的概率计算方式
你的有效广告观看次数
÷
本周全部用户有效观看总次数
计算示例
假设本周所有用户一共完成了 1,000次 有效广告观看，A用户完成了 20次， 那么A用户拥有20次抽奖机会。
20 ÷ 1,000 = 2%
A用户在单个中奖名额抽取中的中奖概率为2%
本周共有5个中奖名额。每位用户每周最多中奖一次，用户中奖后，将不再参与本周剩余名额的抽取。
```

⚠️ 重要活动规则
```
1. 只有完整观看且被系统成功记录的广告，才会计入有效观看次数。
2. 广告未完整播放、网络中断或记录提交失败的，可能不会计入抽奖次数。
3. 同一用户每周最多获得一次大奖，中奖后不再参与当周其他名额的抽取。
4. 严禁使用脚本、自动点击工具、多账户或其他异常方式刷取广告次数。
5. 如系统发现异常观看、作弊或虚假账户，有权取消相关抽奖次数和中奖资格。
6. 中奖概率与有效广告观看次数有关，但观看广告不代表一定能够中奖。
7. 如因系统维护、网络故障或不可抗力导致开奖延迟，新的开奖时间将在活动页面另行通知。
```
