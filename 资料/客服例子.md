# 客服例子

本文档用于说明客服配置接口中 `jump` 字段的推荐填写方式，以及前端当前内置的平台识别映射关系。

## 当前识别规则

前端会综合以下字段识别客服平台：

- `format`
- `title`
- `represent`
- `note`
- `jump`

识别成功后，统一按下面规则处理：

- 先检测设备是否已安装对应 App
- 已安装时优先拉起 App
- 未安装时回退到外部浏览器打开

## format 固定映射表

当前前端已经固定支持下面这组 `format`：

- `format = 1`：外部浏览器打开 `jump`
- `format = 2`：外部浏览器打开 `jump`
- `format = 3`：外部浏览器打开 `jump`
- `format = 4`：Telegram
- `format = 5`：WhatsApp
- `format = 6`：Instagram
- `format = 7`：X / Twitter
- `format = 8`：TikTok
- `format = 9`：Facebook
- `format = 10`：YouTube
- `format = 11`：ShareChat
- `format = 12`：Snapchat

说明：

- `format = 4 ~ 12` 时，前端会优先按固定平台处理。
- 如果 `format` 不是以上值，前端会继续尝试从 `title`、`represent`、`note`、`jump` 中自动识别平台。
- 如果既没有固定 `format`，也识别不到平台，则按外部浏览器打开 `jump` 兜底。

## 当前内置的平台映射关系

### Telegram

识别别名：

- `telegram`
- `tg`
- `t.me`

原生 scheme：

- `tg`

推荐填写例子：

- `novel_service`
- `@novel_service`
- `https://t.me/novel_service`

### WhatsApp

识别别名：

- `whatsapp`
- `wa.me`

原生 scheme：

- `whatsapp`

推荐填写例子：

- `255712345678`
- `+255712345678`
- `https://wa.me/255712345678`
- `https://wa.me/255712345678?text=Hello`

说明：

- 最推荐填写纯手机号，例如 `255712345678`。
- 手机号请尽量使用国际格式，不带空格，不带 `-`。

### Instagram

识别别名：

- `instagram`

原生 scheme：

- `instagram`

推荐填写例子：

- `novel_service`
- `https://www.instagram.com/novel_service/`

说明：

- 最推荐填写用户名，例如 `novel_service`。

### X / Twitter

识别别名：

- `twitter`
- `x`
- `x.com`

原生 scheme：

- `twitter`
- `x`

推荐填写例子：

- `novel_service`
- `https://x.com/novel_service`
- `https://twitter.com/novel_service`
- `https://x.com/novel_service/status/1912345678901234567`

说明：

- 最推荐填写用户名。
- 如果你在 `represent` 中使用 `twitter` 或 `x`，前端都能识别。

### TikTok

识别别名：

- `tiktok`
- `snssdk1233`

原生 scheme：

- `tiktok`
- `snssdk1233`

推荐填写例子：

- `novel_service`
- `@novel_service`
- `https://www.tiktok.com/@novel_service`
- `https://www.tiktok.com/@novel_service/video/7488888888888888888`

说明：

- 最推荐填写用户名。
- 如果你在 `represent` 中使用 `tiktok` 或 `snssdk1233`，前端都能识别。

### Facebook

识别别名：

- `facebook`
- `fb`

原生 scheme：

- `facebook`
- `fb`

推荐填写例子：

- `novelservice`
- `https://www.facebook.com/novelservice`
- `https://www.facebook.com/novelservice/posts/1223456789012345`

说明：

- 最推荐填写主页链接。
- 如果你在 `represent` 中使用 `facebook` 或 `fb`，前端都能识别。

### YouTube

识别别名：

- `youtube`
- `vnd.youtube`
- `youtu.be`

原生 scheme：

- `youtube`
- `vnd.youtube`

推荐填写例子：

- `@novel_service`
- `https://www.youtube.com/@novel_service`
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`

说明：

- 如果是视频链接，前端会优先尝试打开视频。
- 如果是频道地址，前端会优先打开频道。

### ShareChat

识别别名：

- `sharechat`

原生 scheme：

- `sharechat`

推荐填写例子：

- `profile/novel_service`
- `post/xxxxxxxx`
- `https://sharechat.com/profile/novel_service`
- `https://sharechat.com/post/xxxxxxxx`

说明：

- 最推荐填写完整网页链接。
- 也支持填写相对路径，前端会自动补成 `https://sharechat.com/` 开头。

### Snapchat

识别别名：

- `snapchat`

原生 scheme：

- `snapchat`

推荐填写例子：

- `novel_service`
- `https://www.snapchat.com/add/novel_service`

说明：

- 最推荐填写用户名。

## format 字段的补充说明

除了上面的固定 `format` 映射之外，只要以下字段中能识别到平台，前端也会优先按对应 App 处理：

- `title`
- `represent`
- `note`
- `jump`

## 推荐填写方式

如果你要让前端“最稳定地优先拉起 App”，推荐后端按下面方式填写：

- Telegram：`novel_service`
- WhatsApp：`255712345678`
- Instagram：`novel_service`
- X / Twitter：`novel_service`
- TikTok：`novel_service`
- Facebook：`https://www.facebook.com/novelservice`
- YouTube：`https://www.youtube.com/@novel_service`
- ShareChat：`https://sharechat.com/profile/novel_service`
- Snapchat：`novel_service`

## represent 推荐值

如果你希望前端更稳定识别，也建议 `represent` 尽量使用下面这些值：

- Telegram：`telegram` 或 `tg`
- WhatsApp：`whatsapp`
- Instagram：`instagram`
- X / Twitter：`twitter` 或 `x`
- TikTok：`tiktok` 或 `snssdk1233`
- Facebook：`facebook` 或 `fb`
- YouTube：`youtube` 或 `vnd.youtube`
- ShareChat：`sharechat`
- Snapchat：`snapchat`

## 备注

- 目前各平台跳转以“尽量拉起 App，失败则浏览器兜底”为目标。
- 某些平台的 App 内深链规则不如 Telegram、WhatsApp 稳定，所以业务上仍然建议优先保证 `jump` 本身是有效值。
